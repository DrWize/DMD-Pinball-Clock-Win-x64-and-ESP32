DMDClock device API

Local HTTP/JSON reference for this ESP32. All paths are relative to the device address, such as http://DMDClock-59D9/.

← Back to remote
The API is intended for the trusted local network and currently has no authentication or CORS headers. JSON POST bodies must be smaller than 2 KB. Partial settings updates are supported: omitted fields keep their current values.
GET

/api/state — live device state

Returns the current clock, display, settings, network, storage, rendering, touch, NTP and diagnostic state. This lightweight endpoint is suitable for polling and Home Assistant REST sensors.

Display and playback

displayOn, playScene, waitingForScene, sceneIndex, sceneStep, sceneFrame, scene, sceneFile, metadata fields, sceneCount, cycle settings, brightness, glow, theme and information settings.

Time and network

Device time/epoch/timezone, Wi-Fi connection and IP, device/AP identity, NTP state, last-sync epoch, elapsed sync age and configured servers.

Health and diagnostics

Approximate internal chip temperature, RSSI, heap/PSRAM, SD capacity, flash/CPU, boot/reset, frame counters, touch events/errors and settings-backup status.

Playback log

playbackLogEnabled, playbackLogPath, playbackLogPresent and playbackLogBytes.

curl http://DMDClock-59D9/api/state
GET

/api/scenes — complete SD scene catalog

Returns sceneCount and the full scenes array. Each entry contains index, filename, display name, title, game, manufacturer, year and metadata-match status. This response is much larger than /api/state; load it once rather than polling it.

curl http://DMDClock-59D9/api/scenes
POST

/api/settings — update persistent settings

Applies a partial settings object immediately, then mirrors it to NVS and /dmd/config/settings.json. Returns {"ok":true,"wifiReconnecting":false}.

curl -X POST http://DMDClock-59D9/api/settings ^
  -H "Content-Type: application/json" ^
  -d "{\"showInformation\":true,\"brightness\":80}"
POST

/api/action — perform a named control action

Send {"action":"name"}. Successful actions return {"ok":true}.

ActionEffect
pinballNextSelect the first scene belonging to the next metadata game.
sceneNextSelect the next scene within the current metadata game.
colorFamilyNextCycle Basic → Gradient → Raster → Plasma.
colorThemeNextAdvance the subtheme within the current family; advances Plasma palettes in Plasma mode.
toggleInformationToggle the scene-information row.
toggleGlowToggle glow between off and 35%.
syncNtpRestart an immediate NTP synchronization check.
showClockStop the current scene and show the clock.
touchTestStart/restart the guided five-target touchscreen test.
rebootReturn a successful response, then restart the device after a short delay.
 
curl -X POST http://DMDClock-59D9/api/action ^
  -H "Content-Type: application/json" ^
  -d "{\"action\":\"sceneNext\"}"
POST

/api/time — browser/manual clock fallback

Sets Unix time when NTP is unavailable. Send {"epoch":SECONDS}; epoch must be at least 1,700,000,000. The source is reported as Browser until NTP synchronizes.

curl -X POST http://DMDClock-59D9/api/time ^
  -H "Content-Type: application/json" ^
  -d "{\"epoch\":1785369600}"
GET

/ and /api-docs
